Hệ thống MiniCloud gồm 9 dịch vụ • Đang chạy

Mô phỏng một nền tảng Cloud thu nhỏ để học kiến trúc hệ thống hiện đại.

MyMiniCloud bao gồm Web Frontend, Backend API, Database, Keycloak, MinIO, DNS nội bộ, Prometheus, Grafana và API Gateway. Toàn bộ được triển khai bằng Docker Compose trên một mạng ảo duy nhất.
