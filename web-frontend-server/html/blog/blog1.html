Hành trình xây dựng MyMiniCloud – từ Docker đến 9 microservices

MyMiniCloud là dự án giúp mình tiếp cận thực tế mô hình hệ thống cloud thông qua việc tự tay xây dựng 9 dịch vụ: Web Frontend, Backend API, Database, Keycloak, MinIO, DNS nội bộ, Prometheus, Grafana và API Gateway.

Từ một file docker-compose.yml đơn giản, mình học cách cấu hình từng container sao cho chúng giao tiếp được với nhau trong mạng nội bộ cloud-net. Bên cạnh đó, việc phục vụ web tĩnh, reverse proxy qua Nginx, và tích hợp Keycloak để cấp token OIDC giúp mình hiểu rõ hơn về kiến trúc dịch vụ hiện đại.

Khi kết hợp thêm bộ giám sát Prometheus + Grafana, mình thấy được các chỉ số CPU, RAM, Network trong thời gian thực – rất giống với cách các cloud provider quản lý hệ thống thật ngoài đời.
